# Changelog

## 0.1.0 (2026-10-26)

First public preview with all nine modules.

- `senu/struct`: `Deque`, `ValueMap`, `Multimap`
- `senu/object`: `getPath`, `setPath`, `deepMerge`, `stableStringify`, `SecurityError`
- `senu/bytes`: `concatBytes`, `equalsBytes`, `stringToBytes`, `bytesToString`, `toHex`, `fromHex`, `toBase64`, `fromBase64`, `fastHash`
- `senu/async`: `concurrencyLimit`, `mapAsync`, `QueueError`
- `senu/result`: `ok`, `err`, `trySafe`, `trySafeSync`, `isDefect`, `DefectError`
- `senu/boundary`: `parseEnv`, `defineBoundary`, `formatIssues`, `BoundaryValidationError`
- `senu/resilience`: `withResilience`, `isUserAbort`
- `senu/cache`: `createCache`, `CacheError`
- `senu/state`: `safeClone`, `isEqual`, `redact`, `CLONE_SYMBOL`, `StateError`
